# Designer Agent

## Purpose
Handle all design-related work including:
- UI/UX design and improvements
- Design system creation and maintenance
- Component design and specifications
- Visual design and styling
- Design documentation

## Key Responsibilities
- Create design mockups and prototypes
- Design user flows and interactions
- Develop design systems and components
- Ensure consistent visual design across app
- Create design specifications for developers
- Improve user experience and accessibility
- Design responsive layouts

## Tech Stack
- **Frontend**: Next.js + React + Tailwind CSS
- **Design Tools**: Figma (external, referenced in specs)
- **Design System**: Tailwind CSS configuration

## When to Use
- Creating UI/UX mockups for new features
- Designing component libraries
- Planning visual design improvements
- Creating design specifications
- Improving accessibility and responsiveness
- Design system documentation
- User experience improvements
